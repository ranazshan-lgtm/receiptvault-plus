# Receipt Vault + GitHub Pages Website

This is a free static website for Receipt Vault +.

## How to publish for free on GitHub Pages

1. Create a free GitHub account if you do not already have one.
2. Create a new public repository named something like:
   `receiptvault-plus`
3. Upload `index.html`, `logo.png`, and `ReceiptVaultPlus.png` into the repository.
4. Go to:
   Settings → Pages
5. Under "Build and deployment":
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
6. Save.
7. GitHub will give you a free website URL like:
   `https://yourusername.github.io/receiptvault-plus/`

## Before publishing

Replace:
- `support@example.com`
- `[Insert HoldCo Legal Name]`
- App Store link placeholders
- Effective date if desired

Use the GitHub Pages URL as your:
- Privacy Policy URL
- Support URL
- Marketing URL if needed
